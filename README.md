## ✨ Overview

**Atmosly** is a responsive, glassmorphic weather intelligence and atmospheric radar web application designed with multi-hue ambient themes (*Twilight Plum*, *Aurora*, and *Crimson*). Built as a zero-dependency frontend application in a single self-contained architecture (`index.html`), it combines hierarchical regional navigation with instant global search and animated radar telemetry.

---

## 🔥 Core Capabilities

| Module | What It Does |
| :--- | :--- |
| **🗺️ Cascading Regional Atlas** | Drill down seamlessly from **Country → State / Union Territory / Region → Capital / City**, featuring flag indicators and dedicated support for Indian States, Union Territories, and global hubs. |
| **🔍 Multi-Trigger Global Search** | Search any city, state, or capital worldwide with real-time autocomplete suggestions, keyboard (`Enter`) & button submission, quick-flag pills, and persistent recent search chips. |
| **🌡️ Atmospheric Telemetry** | Displays live temperature with instant **°C / °F** unit conversion, *Feels Like* index, High/Low range, 24-hour hourly forecast, and multi-day outlooks. |
| **📡 Interactive Canvas Radar** | Custom HTML5 `<canvas>` atmospheric visualization supporting dynamic layer switching and responsive viewport resizing
